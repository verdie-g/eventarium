This project is a UI that displays in real-time events from GitHub (and others) repositories like commits or comments.

- Feel free to refactor anything when it can improve the quality of the project.
- The project should stay GitHub-agnostic for future support of GitLab, Gerrit, Forgejo, Linear.
- Always fetch the official documentation before touching the code for a provider. Name the classes as defined by the
  documentations.
